# byoa

An open-source library that lets an app run its users' own Claude Code or Codex in any sandbox, with their MCP connections and skills. It runs inside the app's own backend. It is never a hosted service.

- Read `SPEC.md` before you change anything. Every change maps to a requirement (R*) and a check (V*).
- Keep `README.md` and `SPEC.md` true. When behavior changes, update both in the same commit.
- Follow the "Lab rules" in `SPEC.md`: only unmodified `claude` and `codex` binaries, the lab's own sign-in page, no client spoofing.
- Bookish (`madeyexz/ai-native-book-reader`) is the first app. Its `site/agent/` and `src/core/connectors.ts` hold the code this library replaces.
- `skills/byoa/` is the agent skill that teaches a coding agent to add byoa to an app (SKILL.md and `reference/api.md`). When the API changes, update it in the same commit; `test/docs.test.ts` (V12) checks its names.
- The page at https://byoa.rippling.computer is built by `site/build.mjs`: the design (hero, the "Who brings what" diagram, v1 scope) is in `site/template.html`, and the install commands are the code block of "Install" in `README.md`. The page has only the hero, that diagram, "Get started", the v1 scope and a short close; the other README sections stay only in the README. Keep facts in the template true to `SPEC.md`. The page's pixel art is in `site/art/` and its fonts (Geist, OFL) are in `site/fonts/`. `node build.mjs` also writes `site/llms.txt` and `site/llms-full.txt` (https://llmstxt.org) from README.md, SPEC.md, `examples/todo` and `skills/byoa`. After a change to any of them or to the template, run `cd site && npm install && node build.mjs`, and push `site/index.html`, `site/llms.txt` and `site/llms-full.txt` with any changed art or fonts. The README's images in `.github/readme/` (banner, "Who brings what", v1 scope, the closing band, the social preview) are captured from the built page by `site/readme-art.sh`; after a template change that they show, run it after `node build.mjs`. The "Why" panels and the how-it-works, token and lifecycle diagrams are no longer on the page, so their images are kept as they are. The Cloudflare Worker `byoa-site` (`site/worker.js`, custom domain `byoa.rippling.computer`) serves `site/index.html`, `site/llms.txt`, `site/llms-full.txt`, `site/art/` and `site/fonts/` from `main`, so it needs no redeploy unless `site/worker.js` changes. `site/worker.js` itself holds `/robots.txt` (every crawler and AI agent may read every page), `/sitemap.xml` and the IndexNow key file. The zone has a configuration rule that turns Browser Integrity Check off for `byoa.rippling.computer`, because it answered 403 to agent tools that fetch with Python's urllib.
